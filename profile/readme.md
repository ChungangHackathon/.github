# 멋사동네

**기수를 넘어 멋사 동문을 잇는 네트워크 — 모든 기수를 한 곳에, 첫 연락은 가볍게.**

[서비스 바로가기](https://lion-link.vercel.app) · [레포지토리](https://github.com/ChungangHackathon/lion_link) · [API 문서](https://github.com/ChungangHackathon/lion_link/blob/develop/docs/api.md)

</div>

---

## 🧩 왜 멋사동네인가

멋사 활동은 1년 단위로 끝납니다. 기수가 바뀌면 함께 활동한 기억만 남고 **서로를 찾을 방법은 사라집니다.** 회장단조차 자기 기수 명단만 가지고 있어서, 선배 한 명을 찾으려면 기수를 하나씩 거슬러 올라가며 물어야 했습니다.

동문 13명에게 물었더니 **100%** 가 다른 기수 선배에게 묻고 싶은 게 있었다고 답했습니다. 그런데 지금 연락하는 다른 기수 사자가 2명 이하인 사람이 **89%**, 선배가 필요했지만 끝내 닿지 못한 사람이 **75%** 였습니다.

막힌 건 마음이 아니라 길이었습니다. 선배 사자의 **100%** 가 "연락이 오면 도와줄 의향이 있다"고 답했지만, 후배는 *바쁜데 방해될 것 같아서*(**75%**), *먼저 연락하기 부담돼서*(**75%**) 연락하지 못했습니다. 도와줄 마음과 묻고 싶은 마음이 모두 있는데 그 사이가 비어 있었습니다.

멋사동네는 그 사이를 채웁니다. **누구에게 물을지 고르는 건 사용자의 몫**, 그 연락이 부담스럽지 않게 만드는 건 **멋사동네의 몫**입니다.

## ✨ 핵심 기능

1. **동문 찾기** — 1기부터 14기까지 모든 사자를 기수·파트·직무·기술로 검색합니다. 기수 단톡방을 거슬러 올라가지 않아도 됩니다.
2. **커피챗 신청** — "무슨 말로 시작하지"를 신청서 양식이 대신합니다. 주제와 미리 묻고 싶은 질문을 담아 보내면, 받는 사자가 가능한 시간 후보와 함께 수락합니다. 혼자 신청하기 어려우면 동기를 함께 넣어 여러 명이 같이 신청할 수도 있습니다.
3. **안심하고 보내기** — 선배가 미리 켜둔 '커피챗 가능' 표시가 있는 사자에게만 신청이 갑니다. 신청은 14일 뒤 자동으로 만료되고, 거절당하면 같은 사자에게 7일간 다시 신청할 수 없으며, 바쁜 기간에는 쉬는 기간을 걸어둘 수 있습니다. 거절도 부담이 되지 않게 설계했습니다.
4. **채팅 · 게시판** — 수락과 동시에 채팅방이 열려 일정을 정하고, 번개모임과 커뮤니티 게시판으로 한 번의 연결이 1회성으로 끝나지 않게 이어갑니다.

## 🔍 다른 서비스와 뭐가 다른가

| | 단톡방·인맥 | 링크드인 | 에브리타임 | **멋사동네** |
| --- | :---: | :---: | :---: | :---: |
| 모든 동문을 한 곳에서 조회 | ❌ | ⭕ | ❌ | **⭕** |
| 멋사 동문이라는 신뢰 | ⭕ | ❌ | ❌ | **⭕** |
| 신청·응답 구조 | ❌ | ❌ | ❌ | **⭕** |
| 커뮤니티 기능 | ⭕ | ❌ | ⭕ | **⭕** |

링크드인에는 **누구나** 있지만 연락해도 되는 사이인지 알 수 없고, 단톡방은 **우리끼리**지만 다른 기수가 없습니다. 멋사동네는 *우리끼리*면서 *연락해도 되는지 아는* 자리입니다.

## 🏗 레포지토리 구성

| 레포지토리 | 설명 | 주요 스택 |

| [`lion_link/backend`](https://github.com/ChungangHackathon/lion_link/tree/develop/backend) | 구글 로그인·가입 승인, 동문 검색, 커피챗, 실시간 채팅, 커뮤니티, 알림을 담당하는 API 서버 | Java 21, Spring Boot 4, JPA, MySQL 8.4 + Flyway |
| [`lion_link/frontend`](https://github.com/ChungangHackathon/lion_link/tree/develop/frontend) | 동문·대표 모두가 쓰는 웹 클라이언트 | Next.js 16, React 19, TypeScript, Tailwind v4 |

API 95개, 테이블 34개, 백엔드 테스트 799개로 돌아갑니다. 명세는 [`docs/api.md`](https://github.com/ChungangHackathon/lion_link/blob/develop/docs/api.md), 스키마는 [`docs/erd.md`](https://github.com/ChungangHackathon/lion_link/blob/develop/docs/erd.md)에 있습니다.

## 🛠 기술 스택

**Backend**
- Spring Boot 4 · Spring Data JPA · Bean Validation
- Spring Security OAuth2 Client(구글 로그인) · JWT(nimbus-jose-jwt)
- MySQL 8.4 + Flyway 마이그레이션 (테스트는 H2)
- STOMP WebSocket(실시간 채팅), Spring Mail(알림 메일), AWS S3(파일), springdoc(Swagger)

**Frontend**
- Next.js 16 · React 19 · TypeScript
- Tailwind CSS v4, @stomp/stompjs
- 백엔드 없이도 전 화면을 볼 수 있는 프로토타입(mock) 모드

**Infra**
- 백엔드 AWS EC2 · 프론트 Vercel · GitHub Actions CI

## 🚀 로컬 실행

각 폴더의 README를 참고해 주세요.
- Backend: `docker compose up -d` → `cp src/main/resources/application-secret.example.yml src/main/resources/application-secret.yml` → `./gradlew bootRun`
- Frontend: `npm install` → `cp .env.example .env.local` → `npm run dev`
